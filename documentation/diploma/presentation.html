Актуальність дослідження

Проблема

  • Зростання кіберзагроз на 12% щорічно (IBM, 2024)
  • Середня вартість інциденту — $4.45M
  • Традиційні IDS не виявляють zero-day атаки
  • Відсутність контекстуального аналізу
  • Хибно-позитивні спрацювання

Рішення

  • Інтелектуальний аналіз через LLM Llama-3
  • Контекстуальне розуміння логів
  • Автоматична класифікація загроз
  • Генерація рекомендацій людською мовою
  • Локальна LLM — конфіденційність даних

Мета та завдання

Мета: розробити вебдодаток для автоматизованого аналізу мережевого трафіку з використанням LLM Llama-3

Завдання:

  • Аналіз існуючих методів та засобів аналізу мережевого трафіку
  • Дослідження можливостей LLM у кібербезпеці
  • Проектування мікросервісної архітектури (12 контейнерів)
  • Розробка Flask API (9 endpoints) + SPA Dashboard (5 модулів)
  • Реалізація парсера PCAP-файлів
  • Інтеграція з Loki, Prometheus, Alertmanager, Ollama
  • Тестування з імітацією кібератак

Об'єкт: процес аналізу мережевого трафіку та виявлення кіберзагроз

Предмет: методи та засоби розробки вебдодатку з використанням LLM

Data: {logs / PCAP summary}

Output JSON:
- risk_score: 0-10
- threat_found: boolean
- threats[]: type, severity, description
- summary: assessment
- recommendations: mitigation steps
